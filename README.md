Backend-System zur Erstellung und Verwaltung dynamischer Umfragevorlagen mit Fokus auf saubere Architektur und Validierung.

Highlights:
- RESTful API mit Spring Boot
- Domain-Driven Design (Aggregates, Value Objects, Custom Constraints)
- PostgreSQL Persistence mit JPA/Hibernate
- Containerisierte Laufzeit via Docker & Docker Compose
- Automatisierte CI/CD Pipeline mit GitHub Actions (TO DO)
- Validierungs- und Fehlerhandling auf Produktionstauglichem Niveau

Tech Stack:
Java 17, Spring Boot, Hibernate Validator, PostgreSQL, Docker, GitHub Actions
